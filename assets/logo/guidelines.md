# UVE — Logo Guidelines (compact)

## 1. The logo
- **Idea**: a coder at rest, slung in a hammock between code brackets — chill identity for a vibe-coding enjoyer.
- **Versions**: horizontal (`final-horizontal.svg`) · stacked (`final-stacked.svg`) · symbol-only (`final-symbol.svg`) · small-size cut (`final-symbol-small.svg`, use under 32 px).
- **Files**: SVG masters + 1200px PNGs in `design/logo/`; favicon set + `site.webmanifest` + `head-snippet.html` for web.

## 2. Clear space
Keep a clear zone of **1 sun-dot** (the symbol's dot diameter) around the logo on all sides. Scales with the logo.

## 3. Minimum size
| Version | Screen | Print |
|---|---|---|
| Horizontal | 96 px wide | 25 mm wide |
| Symbol | 16 px (use `favicon.svg` / small cut) | 6 mm |

## 4. Colour
| Name | HEX | RGB |
|---|---|---|
| Ultraviolet (primary) | `#5B50E6` | 91, 80, 230 |
| Night LoFi (dark bg) | `#171430` | 23, 20, 48 |
| White | `#FFFFFF` | 255, 255, 255 |
| Black | `#000000` | 0, 0, 0 |

**Approved pairs**: violet on white · white on Night LoFi · white on violet · black on white.
On photos, use white/black on a calm area.

## 5. Typography
- Wordmark is currently set in system rounded sans (`Segoe UI`/`SF Pro Rounded` fallback), **not outlines** — convert to paths (or license a rounded geometric sans) before production use.
- Headlines/body: pick one grotesque + system fallback; keep max two families.

## 6. Don'ts
Don't stretch or squash · don't recolour outside the palette · don't rotate · don't add shadows, outlines, gradients or effects · don't rearrange lockup parts · don't place on busy backgrounds without a container · don't retype the wordmark.

## 7. Handover notes
- Masters are stroke-based (audit 96–97/100, info-only); expand strokes to outlines for cut/print production.
- Library SVGs were study-only references; no tracing used.
- No trademark search performed — run one before commercial use.
- Kit built 2026-10-15 from concept B v2; open items: wordmark outlining, trademark clearance.
